# Sentient Bot releases

Public release channel for **Sentient Bot** by [Sentient Partners](https://sentientpartners.ai).

- **Releases** hold the signed macOS builds and the `latest-mac.yml` metadata the app's auto-updater reads.
- `announcements/announcements.json` is the in-app announcements feed (validated against `announcements.schema.json`).
- `server/model-manifest/model-manifest.json` is the model list installs refresh hourly.

Source code is private. Sentient Bot is built on OpenMausBot under the Apache License 2.0; see `NOTICE`.
